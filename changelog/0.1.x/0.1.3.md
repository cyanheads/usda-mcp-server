# 0.1.3 — 2026-05-24

## Changed

- **`usda_search_foods` description** rewritten for clarity; added note that the data returned is static.
- **`usda_list_nutrients` description** rewritten; updated to say data is static.
- **`usda_compare_foods` description** expanded to name the 12 default nutrients explicitly and clarify partial-match behavior.
- **`usda_get_food` description** revised; `quantity`/`unit` scaling behavior and `scaledTo` output field docs clarified.
- **`usda://nutrients` resource description** updated to list all four tools that accept a `nutrients[]` filter.
- **`usda://food/{fdcId}` resource description** reworded for consistency with `usda_get_food`.
- **Output field descriptions** for `basis`, `scaledTo`, `description`, and `dataType` made more specific across `usda_get_food`, `usda_get_foods`, and `usda_compare_foods`.
- **Code simplification** — barrel `export` statements removed from `tools/definitions/index.ts` and `resources/definitions/index.ts`; conditional property construction in `fdc-service.ts`, `usda-get-food.tool.ts`, and `usda-compare-foods.tool.ts` converted to spread syntax; inline `toGrams` type narrowed to literal union in `usda-get-food.tool.ts`; unused `FdcService` type import removed from `usda-search-foods.tool.ts`; `initFdcService` signature simplified (unused `_config`/`_storage` params removed).

## Fixed

- **`usda_search_foods`** — empty or whitespace-only query no longer reaches the FDC API; fails fast with `query_empty` error ([#1](https://github.com/cyanheads/usda-mcp-server/issues/1)).
- **`usda_get_food` — `quantity` without `unit`** — providing `quantity` without `unit` now throws `quantity_without_unit` instead of silently ignoring the input ([#4](https://github.com/cyanheads/usda-mcp-server/issues/4)).
- **`usda_get_food` / `usda_get_foods` / `usda_compare_foods`** — `fdcId` and `fdcIds` schemas now enforce `min(1)`, rejecting zero and negative IDs at parse time ([#5](https://github.com/cyanheads/usda-mcp-server/issues/5)).
- **`usda_compare_foods`** — `quantity` schema now enforces `.positive()`, preventing zero/negative values from producing corrupt nutrient scaling ([#6](https://github.com/cyanheads/usda-mcp-server/issues/6)).
- **Nutrient reference** — corrected ID collisions: Lactose fixed to 1011, Galactose fixed to 1075, duplicate `Sucrose` entry (id 1010) and duplicate `Vitamin C, total ascorbic acid` entry (id 1123) removed ([#3](https://github.com/cyanheads/usda-mcp-server/issues/3)).

## Security

- **API key** moved from query parameter to `X-Api-Key` request header in `fetchFdc()` — prevents the key from appearing in FDC error response URLs, server access logs, and upstream observability traces ([#2](https://github.com/cyanheads/usda-mcp-server/issues/2)).
