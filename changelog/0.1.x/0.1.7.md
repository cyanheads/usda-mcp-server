# 0.1.7 — 2026-08-13

## Changed

- **`usda_search_foods`** defaults `dataType` to `["Branded"]` instead of `["SR Legacy"]` when `brandOwner` is set and `dataType` is omitted — only Branded records carry a `brandOwner`, so the prior default returned zero hits for any brand search. ([#10](https://github.com/cyanheads/usda-mcp-server/issues/10))
- **README / `.env.example`** clarify `USDA_FDC_API_KEY` is required for FoodData Central-backed calls, not for startup — the server starts and `usda_list_nutrients`/`usda://nutrients` work without a key. ([#11](https://github.com/cyanheads/usda-mcp-server/issues/11))
- **Project scaffold** re-synced to the mcp-ts-core `^0.11.5` template — Socket security scanner and a 3-day `minimumReleaseAge` supply-chain guard in `bunfig.toml`, Dockerfile BuildKit cache mounts and `--omit=peer` installs, `.mcpb` bundles now also strip platform-specific native bindings (`@duckdb/node-bindings-*`), and 27 `skills/*/SKILL.md` files re-synced.

## Fixed

- **`usda://food/{fdcId}`** rejected malformed FDC IDs (`"171077abc"`, `"171077.5"`) by silently truncating them via `parseInt` and returning the wrong food; now validated against a bare positive-integer pattern before parsing. ([#8](https://github.com/cyanheads/usda-mcp-server/issues/8))
- **`nutrients[]`** on `usda_get_food`, `usda_get_foods`, and `usda_compare_foods` accepted negative and zero nutrient IDs; now requires `z.number().int().min(1)`. ([#9](https://github.com/cyanheads/usda-mcp-server/issues/9))
- **`nutrients[]` filtering** returned empty for every input on all three tools — FDC's upstream `nutrients` parameter matches SR numbers while the filter compared FDC ids, so no value satisfied both layers. Filtering now happens only locally, against `id`, after fetching the unfiltered profile. ([#12](https://github.com/cyanheads/usda-mcp-server/issues/12))
- **`nutrient-reference.ts`** rewritten from a live FDC audit — 46 of 148 rows disagreed with FDC on `id`, `number`, or `name`, and three real nutrients (`1013` Lactose, `1014` Maltose, `1123` Lutein + zeaxanthin) had no row at all. Table is now 147 rows, cross-checked against 597 foods across all four FDC data types. ([#13](https://github.com/cyanheads/usda-mcp-server/issues/13))
- **`usda_compare_foods`** default Sugars row requested id `1063`, a Foundation-only nutrient, missing on every SR Legacy/Survey/Branded comparison; default now requests `2000` (`Total Sugars`), reported by all four data types. ([#15](https://github.com/cyanheads/usda-mcp-server/issues/15))
