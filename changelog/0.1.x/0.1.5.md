# 0.1.5 — 2026-06-12

## Added

- **`createApp({ name, title })`** — server identity set explicitly to `usda-mcp-server` rather than relying on the npm-scoped package name.
- **`usda_search_foods` enrichment** — `totalCount` (total matches across all pages) emitted via `ctx.enrich.total()`.
- **Dockerfile `HEALTHCHECK`** — polls `/healthz` every 30s using `bun` (no `curl`/`wget` dependency); adds `org.opencontainers.image.version` label fed by the `APP_VERSION` build arg.
- **`manifest.json`** — `repository`, `homepage`, and `license` fields.
- **`package.json` scripts** — `format:unsafe`, `test:all`, `release:github`.

## Changed

- **Error codes** — `quantity_without_unit`, `too_few_foods`, `query_empty`, and the resource `invalid_id` reason migrated `InvalidParams` → `ValidationError`; `no_portion_data` migrated `InvalidParams` → `NotFound` (a food without portion data is a missing-data condition, not a malformed request).
- **`bundle` script** — pipes the packed `.mcpb` through `scripts/clean-mcpb.ts`; `format` drops `--unsafe` (now `format:unsafe`).
- **`.mcpbignore`** — patterns anchored with leading `/`; `.agents/` and `skills/` excluded from the bundle.
- **README client-config** — server key `usda` → `usda-mcp-server`; npm package corrected to the scoped `@cyanheads/usda-mcp-server`.
