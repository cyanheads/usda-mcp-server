# 0.1.4 — 2026-05-24

## Changed

- **Build scripts** (`build`, `rebuild`, `clean`, `devcheck`, `tree`, `list-skills`, `lint:mcp`, `lint:packaging`, `changelog:build`, `changelog:check`) — migrated from `tsx` to `bun run` for native Bun TS execution.
- **`test` script** — changed from `vitest run` to `bunx vitest run` to align with gold standard.
- **`start:stdio` / `start:http` scripts** — changed runtime from `node dist/index.js` to `bun ./dist/index.js`; removed legacy `start` alias.
- **`engines.bun`** — floor bumped `>=1.3.0` → `>=1.3.2` to match `packageManager`.

## Removed

- **`tsx`** removed from `devDependencies` (no longer needed; all scripts use Bun's native TS runner).

## Added

- **`funding` block** added to `package.json` (GitHub Sponsors + Buy Me a Coffee).
