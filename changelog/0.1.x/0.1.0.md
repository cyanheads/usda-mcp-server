# 0.1.0 — 2026-05-24

## Added

- **`usda_search_foods`** — keyword search across FDC data sources (SR Legacy, Foundation, Survey FNDDS, Branded) with nutrient preview, pagination, and brandOwner filter.
- **`usda_get_food`** — full nutrient profile for one food by FDC ID with optional per-portion scaling (g, oz, lb, kg, serving).
- **`usda_get_foods`** — batch nutrient fetch for 2–20 FDC IDs; failed IDs reported in `failed[]` rather than aborting the batch.
- **`usda_compare_foods`** — side-by-side nutrient comparison for 2–5 foods, formatted as a markdown table with per-food values scaled to a common gram basis.
- **`usda_list_nutrients`** — static FDC nutrient reference table (~150 nutrients) with optional category filter; no API call required.
- **`usda://food/{fdcId}`** resource — full nutrient profile by FDC ID.
- **`usda://nutrients`** resource — complete nutrient reference list.
- **`FdcService`** — wraps USDA FoodData Central REST API (`api.nal.usda.gov/fdc/v1`) with retry, rate-limit handling, and normalization for search, single-food, and batch endpoints.
- 50 tests across all tools and resources.
