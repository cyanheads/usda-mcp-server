# 0.1.8 — 2026-08-13

## Changed

- **`fdc-service.ts`**'s `getFoodDetail` now passes `expectedStatuses: [404]` to `fetchWithTimeout` — a missing FDC ID is the declared `not_found` outcome, not a server fault, so it logs at `debug` instead of `error` (the thrown, status-mapped `McpError` is unchanged). The search and batch paths still log a 404 at `error`, since there it's a genuine anomaly. ([#14](https://github.com/cyanheads/usda-mcp-server/issues/14))
