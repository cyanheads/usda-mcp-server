# 0.2.1 — 2026-11-10

## Added

- **`basisUnit`** on `usda_search_foods`, `usda_get_food`, `usda_get_foods`, `usda_compare_foods`, and `usda://food/{fdcId}` names what the per-100 values are per: `g`, `ml`, or absent when the Branded label unit fixes neither. `usda_get_food` also returns `servingSize`, `servingSizeUnit`, and `householdServingFullText`.
- **`usda_get_foods`** accepts up to 500 `fdcIds`: it fetches the first 20 distinct IDs and returns the rest in `deferredIds` with a notice, counted in `usda.batch.deferrals` ([#38](https://github.com/cyanheads/usda-mcp-server/issues/38)). `USDA_CLAMP_LIMITS=false` restores the 20-entry rejection; the variable is in `.env.example` and the server, plugin, and bundle manifests.
- **`usda_search_foods`** takes `requireAllWords` ([#34](https://github.com/cyanheads/usda-mcp-server/issues/34)) and returns `gtinUpc` on Branded foods. A bare 8–14-digit query without `dataType` searches Branded and Survey (FNDDS) ([#35](https://github.com/cyanheads/usda-mcp-server/issues/35)); printed barcodes that miss FDC's stored digit form are tracked in [#41](https://github.com/cyanheads/usda-mcp-server/issues/41). `usda_get_food` returns `gtinUpc` too.
- **`missingNutrients`** on `usda_get_food` and `usda_get_foods` lists requested nutrient IDs the food does not report; `usda_get_food` no longer renders an empty `### Nutrients` heading ([#37](https://github.com/cyanheads/usda-mcp-server/issues/37)).
- **`usda_compare_foods`** fills a default Energy or Total sugars cell from the food's equivalent nutrient and lists each fill in `substitutions[]`; an explicit `nutrients[]` is never filled ([#36](https://github.com/cyanheads/usda-mcp-server/issues/36)).
- **`result_window_exceeded`** on `usda_search_foods` for a page past FDC's 100,000-result window.

## Changed

- **`usda_search_foods` `brandOwner` and `foodCategory`** match as one phrase instead of any word; a value with `*` or `?` passes through as wildcard terms, and Lucene operators belong in `query` (`+cereal +brandOwner:Kellog*`) ([#32](https://github.com/cyanheads/usda-mcp-server/issues/32)). A `no_results` after a filter names the filter in its message and hint.
- **`usda_get_foods`** returns a repeated `fdcIds` entry once instead of once per occurrence.
- **`usda_compare_foods`** column headers append the FDC ID.
- **Framework** `@cyanheads/mcp-ts-core` ^0.13.18 → ^0.13.22: captured upstream error bodies stay off client error envelopes, abort and timeout edge cases classify as `ServiceUnavailable`, and the tool-error trailer gains a `retry after` term ([v0.13.22](https://github.com/cyanheads/mcp-ts-core/releases/tag/v0.13.22), [v0.13.19](https://github.com/cyanheads/mcp-ts-core/releases/tag/v0.13.19)).
- **Startup and HTTP** from the framework: `createApp()` refuses Node.js below 24, `MCP_PUBLIC_URL` must be an http(s) base URL, `MCP_HTTP_ENDPOINT_PATH` is normalized, and HTTP error responses echo the request's JSON-RPC `id` ([v0.13.20](https://github.com/cyanheads/mcp-ts-core/releases/tag/v0.13.20), [v0.13.21](https://github.com/cyanheads/mcp-ts-core/releases/tag/v0.13.21)).

## Fixed

- **Branded foods labeled in ml or a unit such as IU** were presented and scaled as per 100 g; scaling one off a per-100 g basis now carries a notice ([#29](https://github.com/cyanheads/usda-mcp-server/issues/29)).
- **`usda_get_food` portions** carry `amount`, and descriptions read it (`0.5 cup`) without leaking `undetermined`, FNDDS modifier codes, or a bare `RACC` ([#30](https://github.com/cyanheads/usda-mcp-server/issues/30)).
- **`usda_get_foods` and `usda_compare_foods`** failed with an internal error when every ID was unknown; `usda_get_foods` now returns them all in `failed[]`, and `usda_compare_foods` raises `too_few_foods` ([#31](https://github.com/cyanheads/usda-mcp-server/issues/31)).
- **`usda_search_foods`** returns an empty page with a notice naming the last reachable page for a page past the last, where a page past FDC's result window failed as `query_syntax` ([#33](https://github.com/cyanheads/usda-mcp-server/issues/33)).
- **`usda_get_food`** returns the category for Branded and Survey (FNDDS) foods ([#39](https://github.com/cyanheads/usda-mcp-server/issues/39)).
