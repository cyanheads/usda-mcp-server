# 0.2.0 — 2026-10-25

## Added

- Added the usda-guide skill resource for food selection, serving weights, and missing nutrient coverage.
- **`usda_get_food`** uses a positive finite Branded label serving in `g`, `GRM`, or `GM` when no valid portion exists, with label provenance in `servingInfo` ([#26](https://github.com/cyanheads/usda-mcp-server/issues/26)).

## Changed

- **`usda_search_foods`** projects available protein, fat, carbohydrate, fiber, and four energy IDs in source order, preserving original values and units; use `usda_get_food` for other nutrients ([#24](https://github.com/cyanheads/usda-mcp-server/issues/24)).
- **Install channels** ship the same caller guide through plugins, npm, Docker, and the desktop bundle; bundle cleanup retains the MCP SDK skill runtime.
- **Development tooling** syncs framework skills, packaging checks, and issue forms; setup instructions include hosted and local connection commands.

## Fixed

- **`usda_search_foods`** returns empty success for pages beyond the last matching page, preserving totals and the requested page with an actionable notice ([#25](https://github.com/cyanheads/usda-mcp-server/issues/25)).
